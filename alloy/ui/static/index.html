Step 3 of 3

Fleet starter pipeline

Alloy is healthy. Optionally choose the telemetry for one starter pipeline. These details are used only to render that Fleet manifest; they do not enable local configuration.

No endpoint has to be filled in: any endpoint or tenant you leave blank is written as a REPLACE-ME placeholder that you edit in the generated manifest before downloading it.

gcx creates this pipeline once. The App does not reconcile later changes, disable it, or remove it on uninstall. Continue managing it in Fleet Management after creation.

Replace every REPLACE-ME value with the endpoint and numeric tenant ID from your Grafana Cloud stack, then download it. Edits here are not saved and do not change this App's own configuration.

Then create the pipeline from a machine with gcx installed:

brew install grafana/grafana/gcx
gcx login home-assistant --server https://YOUR-STACK.grafana.net --oauth
gcx config check
gcx fleet pipelines create -f home-assistant-fleet-pipeline.yaml

Traces

When enabled, Alloy listens on OTLP gRPC 4317 and HTTP 4318 on loopback by default.

Binds both receivers to every HAOS interface. Enable only when a trusted network client must send traces; protect the ports with your network firewall.

The OTLP HTTP base endpoint supplied by Tempo or Grafana Cloud.

Numeric Grafana Cloud traces tenant ID or a basic-auth username.

Access-policy token or basic-auth password paired with the traces username.
