# Branding provenance

The packaged artwork is derived from the official **Grafana Cloud** asset set
supplied in the project branding library. No generated imagery is used.

- `icon.png`: `Grafana Cloud/icon/icon_grafanacloud_orange.png`
- `logo.png`: `Grafana Cloud/PNG/grafana_cloud_logo_black.png`

The source artwork is resized without distortion and centred on the standard
Home Assistant App canvases: 128 by 128 pixels for the icon and 250 by 100
pixels for the logo.
